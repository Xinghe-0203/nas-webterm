快捷键与帮助

Windows Terminal 风格的多标签终端

CtrlShiftT新建标签页 CtrlShiftW关闭当前标签页 CtrlTab切换到下 / 上一个标签页 CtrlShiftCV复制选中内容 / 粘贴 CtrlV粘贴（浏览器原生，任何访问方式都可用） 右键粘贴剪贴板 CtrlAltK显示 / 收起 AI 面板 CtrlAltA打开 AI 设置 ShiftEnter把当前输入当自然语言发给 AI ! / #强制当命令 / 强制当对话 Ctrl+-0放大 / 缩小 / 复位字号 AltShift1…9跳到第 N 个标签页 中键关闭点击的标签页

标签栏会每 2.5 秒同步服务端的全部会话（包括其他设备或用户开的窗口）； 关闭标签页会结束该会话并立即释放 PTY 进程与内存。

当前通过 HTTP 访问，浏览器不提供剪贴板读取接口，Ctrl+Shift+V 读不到剪贴板； 请用 Ctrl+V 或右键菜单粘贴。给 fnOS 开启 HTTPS 后即可直接用 Ctrl+Shift+V。

AI 面板里的每条命令默认折叠，点标题展开。只有「删除文件 / 改写或覆盖文件」以及关机、格式化这类不可逆命令需要你确认，其它命令会自动执行。
