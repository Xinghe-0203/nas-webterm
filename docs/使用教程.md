# 更新说明 / 使用教程

这份文档面向使用者和发布者，尽量短。完整细节见 [README.md](README.md)。

---

## 一、安装（普通用户）

1. 下载最新的 `.fpk`：
   - 普通版：`nas-webterm-1.2.5.fpk`
   - AI 版：`nas-webterm-ai-1.2.5.fpk`
2. 飞牛桌面 → **应用中心 → 我的应用 → 手动安装**，选择下载的包。
3. 向导直接点「下一步」，安装完点桌面图标即可打开。

> 图标只对管理员显示，因为它是 root shell。

## 二、终端怎么用

- 直接敲命令，和 SSH 一样。
- `+` 新建标签页，每个标签页是独立 shell。
- 刷新/关掉浏览器不会丢：后台终端继续跑，重新打开自动接回来。
- 关闭标签页会结束该终端里的全部进程。
- 常用：`Ctrl+Shift+T` 新建，`Ctrl+Shift+W` 关闭，`Ctrl+Tab` 切换。

## 三、AI 助手（AI 版）

1. 点面板右上角 **⚙**。
2. 填：
   - 接口地址：`https://api.deepseek.com/v1`（或其它兼容 OpenAI 的服务）
   - API Key
   - 模型名：如 `deepseek-chat`
3. 保存后，在右下角输入框里直接说：
   - 「看看磁盘满了吗」
   - 「装一下 htop」
   - 「把 /tmp 里三天前的日志删掉」
4. 查询类命令自动执行；删除 / 覆盖文件 / 关机这类会弹卡片，点 **执行** 才跑。
5. 面板顶部的 **时钟按钮** 打开聊天记录：刷新、换浏览器都还在，可打开旧对话继续聊。

> Key 只存在 NAS 服务端，不会发送到浏览器。

## 四、升级

- 建议在 **应用中心 → 手动安装** 里覆盖安装新版本。
- 不要用命令行脚本直接 `stop/start`，否则应用中心可能误判为崩溃，导致入口打不开（显示 not found）。
- 遇到 not found：到应用中心把应用 **停止 → 启动**，再重新打开。

## 五、构建（开发者）

```bash
git clone https://github.com/Xinghe-0203/nas-webterm.git
cd nas-webterm
./build.sh --no-test        # 产物在 dist/
```

依赖：Rust 1.75+、Node.js 18+、fnpack（自动下载）、可选 chromium。
详见 README 第 6 节。

## 六、提交代码

本仓库默认分支 `main`。发布流程：

1. 修改 `manifest` 的 `version` 与 `changelog`；
2. 同步 `rust/Cargo.toml`、`web/package.json`、`cmd/main` 的版本号；
3. `./build.sh` 构建并测试；
4. 提交后推送（本机 github.com 直连不稳定，可用 `tools/push-via-api.mjs`）。
